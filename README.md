# TP-Integrador_Web_I
Acá vamos a poner lo referido al TP
## Organización de estilos

- css/base.css: colores, tipografía y estructura general.
- css/header.css: logo, menú, buscador y usuario.
- css/componentes.css: botones reutilizables.
- css/inicio.css: portada, carrusel y tarjetas del inicio.
- css/footer.css: pie de página.

Los ajustes responsive están al final de cada archivo.

## Trabajo en equipo

Cada uno modifica el archivo de la sección que está trabajando.
Los cambios en base.css y componentes.css se coordinan porque
afectan varias páginas.

Para nuevas secciones, agrupar las reglas bajo un comentario
descriptivo. Modificar las reglas existentes antes de agregar
otras repetidas.
